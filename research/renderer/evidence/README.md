# Retained browser evidence

The source-bound final Gate B captures are `browser-proof-desktop-v17.json` and `browser-proof-mobile-v17.json`, with matching `-custom-{numeric,overlays,all,3d}.png`, `-openlayers-{numeric,overlays,all,3d}.png`, and final `.png` screenshots. Desktop is CSS `1440 × 900` at DPR 1; mobile is CSS `390 × 844` at DPR 2. Both use local Vite, OpenLayers `10.10.0`, Playwright `1.60.0`, and pinned headless Chrome `148.0.7778.96`.

The JSON schema binds every result and screenshot to the full canonical fixture SHA-256, source-file digest map, pnpm lock SHA-256, browser identity, and screenshot hashes. Each row switches and renders all 120 numerical layers with a visible known-cell framebuffer sample per layer and multiple distinct samples across the sequence, runs the same raster/vector/overlay/tile workload, records camera-bound framebuffer probes, captures memory/timings/cache counters, and reports 3D support honestly. OpenLayers overlay/all rows use separate actual WebGLVector wall and overlay canvases, with bottom-left readback and a negative color control; its numeric/3D rows keep those vector layers disabled while retaining synchronized map contexts. Custom numeric draws walls alongside its raster, so numeric performance is a within-candidate diagnostic; overlays/all are the cross-candidate vector rows. Custom 3D includes a visible six-floor perspective extrusion probe and a classifier negative test using a background/no-op buffer.

Both reports have zero page errors. Five retained console warnings are headless Chromium `ReadPixels` stall/readback diagnostics; they remain in the reports for performance interpretation. The custom context uses `preserveDrawingBuffer: false`. Raster/vector probes read synchronously in the same render task; the custom 3D probe is sampled after one `requestAnimationFrame` to inspect the completed framebuffer, so that result includes a browser/driver scheduling point and is correctness evidence rather than a GPU-timed metric. Only the final v17 JSON reports and their bound screenshots are retained here.
