# Canonical scene renderer validation

This bounded renderer increment connects the research OpenLayers and custom
WebGL comparison harness to the versioned `kyberia.render-scene/1` document
produced by the Rust rendering adapter. The browser receives the exact Rust
canonical bytes; it does not rebuild or normalize them. Before parsing, a
short-lived module Web Worker calls the exact Rust adapter compiled to WASM.
The browser's admission mirror is a second fail-closed diagnostic boundary,
not a replacement for core validation.

## Reproducible fixture

The checked-in fixture is generated by the standalone research support crate:

```text
cargo run --manifest-path research/renderer/support/canonical-scene/Cargo.toml --locked --offline -- research/renderer/fixtures/canonical-scene-v1.json
```

The generated artifact is 20,404 bytes with SHA-256
`24c2765339aceef830d05e57999e3b435a10092d2782ed9c2153e2c1e306fc8c`.
The fixture intentionally identifies its evidence plane as `Synthetic`; it is
an executable renderer contract fixture and must not be presented as measured
RF evidence.

The Rust adapter currently emits the V1 wire enum as the JSON value `"V1"`.
The browser preserves that value as `wireSchema` and exposes the public
contract identifier separately as `kyberia.render-scene/1`. This distinction
keeps the exact artifact readable while the core wire spelling is migrated in
a separately reviewed adapter change.

## Browser admission contract

`research/renderer/scene-validator-worker.js` loads the checked-in
`wasm/kyberia_scene_validator_wasm.wasm` and calls the bounded ABI from
`support/scene-validator-wasm`. Rust status `0` is the only status that allows
the JavaScript mirror to continue. Worker errors, unavailable WebAssembly or
Workers, resource rejection, unsupported versions, malformed/noncanonical
bytes, and cancellation are surfaced explicitly. Each request has a 10-second
deadline; the worker aborts its artifact fetch at that deadline, and a fresh
worker is terminated on timeout, cancellation, or completion. This bounds a
malicious or crashing import's lifetime.

`research/renderer/scene.js` admits a scene only after all of the following:

- byte, nesting, string, collection, and contribution bounds are checked before
  JSON parsing or derived-array allocation, including array cardinalities;
  duplicate keys and non-canonical whitespace are rejected during preflight,
  while object-field order is checked immediately after parsing and before any
  derived layer is created;
- the wire schema, object fields, IDs, hashes, exact decimal counts, finite
  numbers, frame/floor binding, and evidence states are validated;
- the metric definition bytes match both recorded hashes and one of the
  canonical observed-RSSI metric identities, including its dBm semantics and
  spatial method;
- sample, location-group, aggregate, support, contributor, unknown, and
  extrapolation invariants are checked;
- the browser independently replays the supported signal aggregate and point,
  nearest, and IDW cell semantics and rejects a value, class, support,
  contributor, aggregate, or unsupported uncertainty mutation;
- metric artifact version and media type are bound to the metric identity and
  the canonical Kyberia media type;
- SHA-256 verification and cancellation checks complete before a display layer
  is published.

The support adapter is intentionally a research-only C ABI and contains no
domain-facing renderer types. Rebuild and verify through `npm run check:wasm`
from `research/renderer`; a bare Cargo command omits the owned path-remapping
environment and is not the reproducible artifact procedure. A source change
leaves the new candidate in the ignored support target directory. Compare
independent checkout builds and review their source, digest and admission tests
before replacing the checked artifact and sidecar; retain the old artifact in
a unique trash entry.

The current artifact SHA-256 is recorded in
`wasm/kyberia_scene_validator_wasm.wasm.sha256` and is asserted by the Node
contract tests. A changed binary therefore requires an explicit digest review
before it can pass the renderer checks; the sidecar does not claim to replace
the pinned Rust source/toolchain build procedure.

Run the reproducibility check from `research/renderer/` with:

```text
pnpm run check:wasm
```

This invokes `cargo build --target wasm32-unknown-unknown --release
--locked --offline` from the repository root, so `rust-toolchain.toml` selects
the pinned toolchain and the primary workspace lockfile selects the exact
dependency graph. The validator is a workspace composition member, with
checkout/registry path remapping and inherited compiler/profile overrides
removed from its build environment. It compares the resulting ignored `support/scene-validator-wasm/target`
artifact byte-for-byte with the checked-in WASM and its sidecar digest. A
missing target, unavailable pinned toolchain, offline dependency, or changed
source produces a failing result; the command never installs dependencies or
overwrites the reviewed artifact.

The direct admission regression in `scene.test.mjs` covers the canonical
fixture, valid Rust-generated `PointValue` and `Nearest` method fixtures, an
escaped `"V1"` string, and an alternate `8.0` number. This catches
the exact class of representation drift that a JavaScript object validator
cannot observe. `loadCanonicalScene` always invokes the Rust worker; callers
cannot omit that admission by leaving an option unset. The explicitly named
`loadCanonicalSceneMirror` path is retained for diagnostic replay tests only.

Known values are copied to a numeric `Float32Array`; unknown values become
`NaN` with mask `0`. The mask is retained alongside the value so an unknown
cell cannot be interpreted as zero. The inspector exposes the raw evidence
state, reason, support counts, uncertainty, contributor weights, frame, floor,
grid center, metric identity, source hash, and evidence plane as text.

Numeric layers are discrete cell rasters. The custom WebGL texture uses
`NEAREST` minification and magnification with `CLAMP_TO_EDGE`, so an interior
sample always reads one canonical cell's value and mask; RGBA interpolation
cannot blend a known RSSI with an unknown zero-alpha texel. The OpenLayers
`ImageCanvas` source disables interpolation, and its canvas copy disables 2D
image smoothing. The browser regression samples the known
cell center and both interior edges plus the adjacent unknown cell center and
shared edge; it requires identical known colors and an unknown pixel class in
both renderers.

## UI and failure behavior

The default source is the bundled canonical scene. A user may select another
canonical JSON file, cancel its admission, or explicitly choose the synthetic
Gate B stress fixture. A malformed, unsupported, over-sized, hash-invalid, or
cancelled canonical load remains an explicit status and does not silently
replace its evidence with synthetic data. The file input is bounded before
`arrayBuffer()` is requested, and an invalid or cancelled replacement clears the
previous raster and renderer publication. Canonical raster bounds and
coordinate readouts come from grid origin, offsets, resolution, and dimensions;
they do not assume the synthetic 4096×3072 fixture. Arrow keys and the visible
camera buttons provide keyboard camera movement; all important values are
available in the textual inspector and coordinate readout.

The synthetic source remains available to exercise the existing 120-layer,
10,000 AP, 10,000 path, tile-cache, and six-floor comparison workload. That
workload is not evidence that a canonical scene contains those overlays.

## Checks

From `research/renderer/`:

```text
node --test *.test.mjs
node --check renderer.js
node --check scene.js
node --check scene-validator-worker.js
node --check browser-canonical-scenes.mjs
```

The canonical scene tests cover successful admission, exact geometry and
unknown preservation, numerical replay tampering, unknown fields, unsupported
versions, nonfinite values, hash mismatch, a same-unit metric impostor, strict
canonical JSON, duplicate keys, metric artifact binding, aggregate and
uncertainty replay, pre-parse array limits, size limits, and cancellation during
admission.

With the local Vite server running, the executable browser smoke test writes
retained screenshots and a JSON result under an explicitly supplied ignored
directory:

```text
node browser-canonical-scenes.mjs http://127.0.0.1:4173/index.html .trash/browser-canonical-scenes
```

It checks desktop and mobile DPR2 viewports, canonical grid bounds, horizontal
overflow, duplicate-key rejection through the real file input, clearing of the
previous publication after rejection, the WASM admission worker, discrete
known/unknown raster sampling near cell boundaries, and the OpenLayers candidate. The Browser
plugin was unavailable during this run; the pinned local Playwright package is
the documented fallback. Screenshots are validation artifacts, not RF evidence.

The existing Playwright browser proof remains the comparison/runtime gate. The
Browser plugin was unavailable to this agent; use the pinned Playwright package
